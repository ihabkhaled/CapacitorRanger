# Marketing module

Owns the public About, Features, FAQ, and Contact pages. Copy is resolved in the hook from the
canonical locale catalogs; the shared page component only renders prepared view data.

## Public surface

- `getMarketingRouteDefinitions` registers the four public locale-first route patterns.
- `aboutPath`, `featuresPath`, `faqPath`, and `contactPath` expose canonical route patterns.

## Invariants

- Every public path begins with `/:locale`; concrete links use `localizedPath`.
- The contact address is declared once in `marketing.constants.ts`.
- Static HTML metadata is generated by `scripts/build/generate-static-site.mjs` from the same page
  and locale inventory documented in `context/routing-map.md`.
